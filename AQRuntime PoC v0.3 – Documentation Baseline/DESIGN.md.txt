# 2. Component Design

## Hardware Detector (`src/aqruntime/hardware/detector.py`)
- Queries total system RAM, free RAM, and CPU core counts.
- Computes maximum recommended model parameter size (e.g. 16GB RAM -> max 3.8B parameters FP16).

## Catalog Manager (`src/aqruntime/catalog/manager.py`)
- Reads offline permanent catalog cache `config/catalog_cache.json`.
- Queries Hugging Face Hub API for live model search when online.
- Updates local catalog cache file when online results are retrieved.
- Scores and filters models based on `HardwareDetector` capacity.
