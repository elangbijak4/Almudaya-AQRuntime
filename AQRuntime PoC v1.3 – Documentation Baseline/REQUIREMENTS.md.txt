# REQUIREMENTS.md

# AQRuntime Software Requirements Specification

Version: PoC v1.3

---

# 1. Functional Requirements

- FR-001: Download AI Model from Hugging Face repository.
- FR-002: Store Model in local storage using sanitized repository identifier (`owner-repository`).
- FR-003: List installed models safely.
- FR-004: Load AI Model using RAM-optimized parameters (`low_cpu_mem_usage`, auto dtype).
- FR-005: Interactive Inference execution with multi-turn conversation context.
- FR-006: User Prompt input via CLI.
- FR-007: Model Response generation with chat template formatting.
- FR-008: Exit Session when requested with clean memory release.
- FR-009: Remove Model by name or alias.
- FR-010: Version Information display.
- FR-011: Multi-model Storage Isolation.
- FR-012: Hardware Detection of system RAM and computing capacity.
- FR-013: Smart Model Discovery (`aq discover`).
- FR-014: Gated Model Detection and step-by-step guidance.
- FR-015: Hugging Face Token Authentication (`aq login`).
- FR-016: Short-Term Memory sliding window context management.
- FR-017: Long-Term Memory persistence in local JSON files.
- FR-018: Memory session management subcommands (`aq memory list/clear/export`).
- FR-019: Pre-installation hardware diagnostic check & minimum requirement verification (`aq doctor`).
- FR-020: Minimum model recommendation guidance.
- FR-021: Pre-download model file size estimation.
- FR-022: Pre-download interactive confirmation prompt.
- FR-023: Non-interactive confirmation bypass flag (`aq pull --yes`).
- FR-024: Local HTTP REST API Server launch (`aq serve`).
- FR-025: OpenAI-compatible `/v1/chat/completions` endpoint.
- FR-026: OpenAI-compatible `/v1/models` list endpoint.
- FR-027: Health check `/health` endpoint.
- FR-028: Custom System Prompt override support (`--system`).
- FR-029: Launch Integrated Web UI Dashboard via single command (`aq ui`).
- FR-030: Automatic default web browser launch on `aq ui`.
- FR-031: Serve Embedded Single-Page Dashboard (`/ui`).
- FR-032: REST API endpoints for hardware diagnostics and memory actions.
- FR-033: GGUF 4-bit / 8-bit model file format detection and loading (`src/aqruntime/model/gguf_loader.py`).
- FR-034: Ultra-low RAM footprint execution for GGUF models.
- FR-035: GGUF discovery catalog models tagged `[GGUF-Q4]`.
- FR-036: GGUF hardware threshold calculation (`max_safe_param_size_gguf()`).
- FR-037: Fix chat messages scrolling behavior in GUI.
- FR-038: 5-Tab Desktop Control Center Web GUI representing full CLI suite visually.
- FR-039: Async background model download execution.
- FR-040: Live download status polling API endpoint (`GET /api/pull/status`).
- FR-041: Real-time download progress modal with Resume indicator in Web GUI.
- FR-042: Inspect download state API endpoint (`POST /api/pull/inspect`).
- FR-043: Alert user if model is already 100% installed.
- FR-044: Display Interactive Resume Modal with cached progress bar for partial downloads.
- FR-045: Provide "Lanjutkan Pengunduhan (Resume)" button.
- FR-046: Provide "Reset & Unduh dari Awal" button with confirmation prompt (`POST /api/pull/reset`).
- FR-047: OS Power Lock Manager (`PowerLockManager`) acquiring execution lock during model downloads.
- FR-048: Browser Screen Wake Lock API (`navigator.wakeLock`) preventing screen/tab sleep during downloads.
- FR-049: Display live protection badge (`🛡️ Sleep Lock Active`) during active downloads.

---

# 2. Non-Functional Requirements

- NFR-001: Automatic release of power locks upon download completion or error.
