# REQUIREMENTS.md

# AQRuntime Software Requirements Specification

Version: PoC v0.6

---

# 1. Functional Requirements

- FR-001: Download AI Model from Hugging Face repository.
- FR-002: Store Model in local storage using sanitized repository identifier (`owner-repository`).
- FR-003: List installed models safely.
- FR-004: Load AI Model using RAM-optimized parameters (`low_cpu_mem_usage`, auto dtype).
- FR-005: Interactive Inference execution with multi-turn conversation context.
- FR-006: User Prompt input via CLI.
- FR-007: Model Response generation with chat template formatting.
- FR-008: Exit Session when requested with clean memory release.
- FR-009: Remove Model by name or alias.
- FR-010: Version Information display.
- FR-011: Multi-model Storage Isolation.
- FR-012: Hardware Detection of system RAM and computing capacity.
- FR-013: Smart Model Discovery (`aq discover`).
- FR-014: Gated Model Detection and step-by-step guidance.
- FR-015: Hugging Face Token Authentication (`aq login`).
- FR-016: Short-Term Memory sliding window context management.
- FR-017: Long-Term Memory persistence in local JSON files.
- FR-018: Memory session management subcommands (`aq memory list/clear/export`).
- FR-019: Pre-installation hardware diagnostic check & minimum requirement verification (`aq doctor`).
- FR-020: Minimum model recommendation guidance when hardware specs pass minimum threshold.
- FR-021: Pre-download model file size estimation.
- FR-022: Pre-download interactive confirmation prompt (`Proceed with download? [y/N]`).
- FR-023: Non-interactive confirmation bypass flag (`aq pull --yes`).

---

# 2. Non-Functional Requirements

- NFR-001: Clear, friendly user feedback on hardware limits and file download sizes.
- NFR-002: Graceful abort without network resource waste on cancellation.
