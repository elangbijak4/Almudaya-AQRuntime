# AQRuntime Testing Specification

Version: PoC v0.1

---

# 1. Overview

This document defines the testing procedures for AQRuntime Proof of Concept (PoC) Version 0.1.

The objective is to verify that every functional requirement has been successfully implemented.

---

# 2. Test Environment

Operating System

- Windows
- Linux
- macOS

Execution Mode

- Command Line Interface (CLI)

---

# 3. Test Cases

## TC-001 Runtime Version

Objective

Verify runtime version information.

Command

```bash
aq version
```

Expected Result

```
AQRuntime
Version 0.1.0
```

Status

PASS

---

## TC-002 Download Model

Objective

Verify model download.

Command

```bash
aq pull TinyLlama/TinyLlama-1.1B-Chat-v1.0
```

Expected Result

```
Downloading model...

Completed.
```

Status

PASS

---

## TC-003 List Installed Models

Objective

Status

PASS

# 6. Pass Criteria

AQRuntime PoC v0.1 shall be accepted when:

- All test cases pass.
- All functional requirements are satisfied.
- Interactive inference operates successfully.
- Runtime exits normally.
- No critical runtime errors occur.
