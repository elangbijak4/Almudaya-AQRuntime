# 3. Evolution Summary

PoC v0.5 introduces:
- Short-Term Memory (in-session token sliding window).
- Long-Term Memory (persistent JSON memory store in `memory/`).
- User privacy controls (`--memory`, `--no-memory`, `--session`).
- Memory management subcommands (`aq memory list`, `aq memory clear`, `aq memory export`).
